# Description of the Database System
This project is a relational database system developed for managing supermarket retail and supply chain operations. 
The system stores and manages information about suppliers, products, customers, orders, payments, inventory, stores, employees, and jobs.

The database system helps improve:
- Inventory management
- Supplier tracking
- Customer order processing
- Payment management
- Employee and store management
The project was implemented using SQL Server Management Studio (SSMS).


# Tables Created

2. Product
3. Customer

5. OrderItems

8. Inventory
9. Job
10. Employee
